# Base Minerals

Base Minerals adds lithium, niter, phosphorus, potash, salt, saltpeter, silicon
and sulfur. It provides powders, storage blocks and, for some materials,
ingots, blends and molten forms. Silicon is made from sand and coal or charcoal
dust. The seven ores use KiriCattus's overlays on Minecraft's stone texture.

This branch targets Minecraft 1.12.2 and Forge 14.23.5.2859 or later. Install
MMDLib 1.0.0 RC3 and OreSpawn 4.1.6.112021 on the client and server. Base Metals
and Mineralogy are optional. Tinkers' Construct adds melting and casting for
lithium and silicon.

The material and fluid settings in `config/BaseMinerals.cfg` require a full
restart. Open the same screen from Forge Mods or OreSpawn's Mods directory.
Configure ore placement and shared outputs in OreSpawn. Vanilla stone and its
variants are valid hosts.

Registry names and the 1.12 config keys carry forward. OreSpawn preserves saved
profiles, imported rules and already generated chunks. If you are moving an
OreSpawn 1 setup from 1.10.2 or 1.11.2, import it there first and carry the
saved world profile forward.

See [ore generation](docs/ORE_GENERATION.md), [building](docs/BUILDING.md) and
[verification](tools/validation/legacy112/README.md).
